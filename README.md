# solidity-course

This repository is my hands-on practice space for learning Solidity and basic smart contract development.

## What it includes

- `SimpleStorage.sol`: a beginner contract for storing values and working with structs, arrays, and mappings
- `StorageFactory.sol`: a contract factory example
- `FundMe.sol`: an early funding contract experiment
- `artifacts/`: generated contract artifact output

## Why I built it

I used this repo while following a Solidity course and testing examples in Remix IDE, with the goal of learning the language and the fundamentals of Ethereum smart contracts.
